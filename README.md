How It Works Now:



Upload your image in the Segment Loader node

Connect coordinate\_preview output to a Preview Image node

Adjust coordinates (X, Y, width, height) and grid spacing as needed

Run the workflow to see the updated grid preview

Fine-tune coordinates based on the visual feedback

Process the segment with your editing nodes



The coordinate preview shows:



White grid lines with customizable spacing

Gold coordinate numbers on all edges

Bright pink selection rectangle with corner markers

Info panel showing selection details and grid spacing
